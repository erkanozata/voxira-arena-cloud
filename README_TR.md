# VOXIRA ARENA CLOUD
Telefon yayını + Render Node.js sunucusu. Bu proje gerçek TikTok LIVE üzerinde henüz test edilmedi.

## Render kurulumu
1. Bu klasörün dosyalarını bir GitHub deposuna yükleyin (server.mjs, package.json ve public klasörü).
2. render.com > New > Web Service > GitHub deponuzu seçin.
3. Runtime Node, Build Command: npm install, Start Command: npm start.
4. Environment > TIKTOK_USERNAME = voxiralive.
5. Deploy bitince https://...onrender.com adresini telefonda Chrome ile açın.
6. TikTok > + > CANLI > Mobil oyun > CANLI Yayın Yap > tüm ekranı paylaş > Chrome'a dönün.
7. Başka hesaptan yoruma mavi/kırmızı yazın ve gül göndererek deneyin.

## Önemli
- TikTok LIVE Connector gayriresmîdir. Erişim değişebilir veya bağlanmayabilir.
- Hediye gönderen kişi önce mavi/kırmızı yorumuyla takım seçmelidir.
- Gül +5 asker; diğer hediye +15 asker; aslan +60 asker.
- Ücretsiz Render planı uykuya geçebilir ve sunucu yeniden başlayınca takım bilgileri sıfırlanır.
- İlk testte bir başka hesaptan gerçek yorum ve gül gönderimi gerekir. Test butonları gerçek hediye değildir.
- Android'de ekran kapanmamalı; rahatsız etmeyin modunu açın.
